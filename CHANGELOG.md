# Changelog

All notable changes to TruthSync are documented in this file.

## [0.1.0] - 2026-08-16

### Added

- GitHub Action and local CLI for deterministic documentation-drift checks.
- Status contradiction detection for structured metadata and nearby prose.
- JavaScript package-script and Python tool validation against project manifests.
- Explicit documentation-version checks against the root package manifest.
- GitHub annotations, job summaries, result outputs, and JSON evidence reports.
- Configurable include/exclude paths, rule selection, Python tools, and failure thresholds.
